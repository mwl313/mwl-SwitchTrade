SwitchTrade release source
--------------------------

The complete application source and release history are available at:
https://github.com/mwl313/mwl-SwitchTrade

The package manifest records the exact source commit as release_id. The packaged WSL payload also
contains the corresponding Python and shell source. To request the source for a distributed build,
open an issue at https://github.com/mwl313/mwl-SwitchTrade/issues and include its release_id.

Custom WSL kernel
-----------------

The SwitchTrade kernel is built without proprietary source changes from Microsoft's WSL2 Linux kernel
tag linux-msft-wsl-6.18.35.2. Linux is licensed under GPL-2.0-only WITH Linux-syscall-note; additional
licenses apply to individual kernel files. Exact source:
https://github.com/microsoft/WSL2-Linux-Kernel/tree/linux-msft-wsl-6.18.35.2

The reproducible configuration and any external-driver patch are available in this release source at
scripts/wsl2/github-build. The optional RTL8188EU vendor module is experimental and is not included in
the default beta kernel artifact.
