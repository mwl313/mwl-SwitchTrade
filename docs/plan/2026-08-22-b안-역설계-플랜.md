# B안 역설계 플랜 — hostapd nl80211 시퀀스 역공학 (2026-08-22 밤)

> 목표: ldn create_network의 START_AP 후 **rtl8xxxu가 beaconing을 시작하지 않는 원인**을
> hostapd -dd 로그 역공학으로 특정하고, ldn에 누락된 nl80211 명령을 추가하여
> **hostapd 없이 beacon 송출을 시작하게 만든다.**
> 조건: 스위치 불필요. VM1(8192EU) + VM2(8188EU, 스캐너). 무인 롱러너.

---

## 체크포인트

| # | 작업 | 완료 기준 | 담당 |
|---|---|---|---|
| B1 | hostapd -dd 전체 로그 수집 | nl80211 명령 시퀀스 파일 확보 | 아리아 직접 |
| B2 | 로그에서 nl80211 명령 추출·분류 | 명령 목록 문서화 (docs/18-b2) | 아리아 직접 |
| B3 | ldn _start_ap와 gap 분석 | 누락 명령 특정 (docs/18-b3) | 오픈코드 |
| B4 | ldn wlan.py 패치 구현 | 커밋 + 오프라인 테스트 통과 | 오픈코드 |
| B5 | 오프라인 검증 | 전체 테스트 통과 | 아리아 직접 |
| B6 | VM1 실기 검증: beacon 송출 확인 | tcpdump에서 자기 beacon ≥1 | 아리아 직접 |
| B7 | VM2 스캔 found ≥1 | ldn.scan에서 EMU 방 발견 | 아리아 직접 |

---

## B1 실행 절차

1. VM1에서 hostapd를 포그라운드 -dd로 실행 (30초)
2. 전체 로그를 파일로 저장
3. Mac으로 복사
4. nl80211 명령 라인만 필터링
