## 🔍 새로 발견한 문제 (미해결)

### 채널 불일치 정황
- 한 차례 자유 스캔에서 `ch=1`로 광고 관측 → CH1 고정 수신에서도 PASS 재현
- 그러나 CH6 고정 수신도 여러 번 PASS → **광고가 CH6와 CH1 양쪽에서 관측되는 혼조**
- 의심: ldn의 Vendor Action TX가 채널 호핑을 하거나, 모니터 수신기의 채널 컨텍스트 오염

### VM2 반복 스캔 부작용 (현재 막힘)
- ldn scan이 매번 vif(`ldn-ad-check`)+소켓을 남김 → fd/vif 누적
- `Too many open files` / `scan timed out` 반발
- authorized 토글로는 회복 불능 상태에 도달
