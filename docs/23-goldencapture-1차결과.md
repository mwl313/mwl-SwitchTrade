## 3. 가능한 원인 (우선순위)

### P-A. NSO GBA 앱이 "인터넷 모드"로 동작했을 가능성 ⭐ 유력
NSO GBA 앱은 로컬 무선(LDN) 대신 **인터넷 경유 온라인 매칭**을 쓸 수 있음.
- 근거: 스위치들이 SK공유기에 연결되어 활발히 Data 주고받음 (IV 증가 = 암호화 통신 실시간 진행)
- NSO 앱 특성상 "다이렉트 커넥션"이라도 내부적으로는 인터넷 릴레이를 먼저 시도할 수 있음
- **검증**: 스위치 비행기 모드 or 공유기 연결 해제 후 로컬 통신 재시도 → 이때 캡처하면 LDN 프레임이 나옴

### P-B. LDN 채널이 CH6가 아님
- FRLG NSO 버전의 로컬 무선이 CH6 외 채널(1/11 등)을 쓴다면 놓쳤을 것
- **검증**: 채널 호핑 캡처(CH1→6→11 순차) 또는 스위치 통신 시작 전 각 채널 관측

### P-C. 두 스위치가 서로를 못 찾아 LDN 세션이 아예 안 열림
- 주인님 보고: "교환 불가 포켓몬으로 중단" → 재시도. 중간에 방 검색 실패 구간이 있었을 수 있음
- **검증**: 다음 시도 때 화면 녹화 병행
