# MWL-SwitchTrade — 프로젝트 브리프 (v0.1, 킥오프)

> **프로젝트명: MWL-SwitchTrade** — 순정 Nintendo Switch의 공식 Game Boy 서비스 포켓몬 게임을 인터넷으로 연결하는 트레이딩 시스템.

---

## 1. 한 줄 정의

**Nintendo Switch Online 공식 Game Boy/GBA 앱에서 실행되는 포켓몬 게임(FRLG 우선)의 트레이딩을, 홈브류·커스텀 펌웨어 없이 순정 상태 그대로, 인터넷을 통해 두 Switch 간에 가능하게 하는 시스템.**

## 2. 배경 — 왜 필요한가

- Switch의 NSO 공식 Game Boy 앱은 **로컬 무선 통신만 지원**한다. 인터넷에 연결된 기기인데도 온라인 트레이드/배틀 기능이 없다.
- 순정 상태에서의 통신 수단은 게임 내 "로컬 무선" 하나뿐이고, 이는 실제로 **Switch 시스템의 LDN(Local Domain Network) 프로토콜** 위에서 동작한다.
- LDN은 데이터 링크 레이어 수준의 로컬 무선 프로토콜이지만, **PC가 Wi-Fi 카드로 LDN 네트워크에 참가할 수 있다**는 것이 이미 커뮤니티에서 증명됨 (frlg-ldn-trade, 2026-06).
- 즉, "Switch는 로컬 무선으로 통신할 뿐"이고, 모든 원격 연결 마법을 **PC 브리지**가 담당하면 순정 상태가 유지된다.

## 3. 목표

| # | 목표 | 상세 |
|---|------|------|
| G1 | **인터넷 트레이딩** | 서로 다른 장소의 Switch 2대 (NSO FRLG) 간 트레이드 성공 |
| G2 | **순정 유지** | Switch 측 작업 0 — 홈브류/커펌/개조 일절 없음. 통신은 게임 내 로컬 무선 기능만 사용 |
| G3 | **세션 시스템** | 세션 ID 공유로 두 사용자 간 매칭 (방 생성/참가) |
| G4 | **(확장) 온라인 배틀** | 같은 인프라로 실시간 배틀까지 |
| G5 | **(확장) Gen 2 지원** | NSO GB 앱의 GSC 트레이딩도 동일 아키텍처로 커버 |

## 4. 제약 (하드 제약)

- **순정 Switch/Switch 2** — 홈브류, 커스텀 펌웨어, 하드웨어 개조 금지.
- Switch 측 요구는 "게임을 디렉트 코너(통신실)까지 진행"하는 것뿐.
- **PC 측 요구는 허용** (브리지 역할): Linux + 호환 Wi-Fi 카드 + (가능하면) prod.keys.
- 닌텐도 서비스 ToS와의 관계: 비공식 커뮤니티 프로젝트로, 개인 사용·연구 목적 범위에서 진행.

## 5. 핵심 아키텍처 (개념)

```
[Switch A] ──LDN 로컬 무선──> [PC 브리지 A] ──인터넷 터널/릴레이──> [PC 브리지 B] <──LDN 로컬 무선── [Switch B]
   NSO FRLG                     가상 GBA 플레이어                   가상 GBA 플레이어        NSO FRLG
```

- 각 PC는 자기 Switch에게 **"가상의 상대 플레이어(GBA)"**처럼 보인다 (frlg-ldn-trade가 이미 증명한 동작).
- PC 브리지 둘이 인터넷으로 연결되어, 트레이드 패킷을 양방향 중계한다.
- Switch는 모든 과정에서 "로컬 무선으로 옆에 있는 상대와 통신 중"일 뿐.

## 6. 범위

### 포함 (In Scope)
- FRLG (FireRed/LeafGreen) 온라인 트레이드 — 우선 목표
- 세션 ID 기반 매칭 (2인)
- .pk3 파일 지원 (PC↔Switch 양방향)
- Windows/macOS에서도 동작하는 PC 브리지 클라이언트 (Linux 서버는 코어)

### 제외 (Out of Scope — 초기 단계)
- Switch 커스텀 펌웨어/홈브류 관련 모든 것
- 닌텐도 공식 온라인 인프라와의 통합
- 5인 이상 멀티 (FRLG 무선 한계 검토 후 결정)
- 모바일 앱

## 7. 관련 프로젝트 지형도

| 프로젝트 | 레이어 | 우리 프로젝트와 관계 |
|---|---|---|
| **kinnay/LDN** | LDN 프로토콜 (링크/네트워크) | **기반 라이브러리** — 스캔/참가/호스트 |
| **tornadus/frlg-ldn-trade** | FRLG RFU 게임 시뮬레이션 | **게임 레이어의 핵심** — PoC 재현 + 확장 대상 |
| **GB-Link (Celio)** | GBA 링크 케이블 인터넷화 | **아키텍처 참고** — 세션/릴레이/클라이언트 패턴 (단, 대상이 실기 GBA) |
| **Celio-Server** | Socket.IO 릴레이 서버 | **릴레이 서버 설계 참고** |

## 8. 미싱 링크 요약 (자세히는 01-assessment.md)

1. **PC↔PC 인터넷 터널/릴레이 서버** — 현재 아무도 만들지 않은 부분 (신규 개발)
2. **frlgsim 안정화** — 현재 PoC 수준 (연결 재시도, 양방향 트레이드 안정화)
3. **세션 ID 매칭 + 클라이언트 UI** — Celio 패턴 적용 (신규 개발)
4. **prod.keys 의존성 검증** — 순정 제약과의 충돌 여부 확인 필요 (리서치 포인트)
5. **호환 Wi-Fi 카드 확보** — Linux 환경 + USB/PCIe 카드 필요
