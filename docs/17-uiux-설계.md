## 0. 이 세션의 범위

GUI·UIUX 디자인 논의 전용. 코딩 없이 시스템의 최종 모양을 설계한다.
framerelay 전환으로 UI의 본질이 "게임 도구"에서 **"연결 도우미"(카톡 화면공유류 멘탈 모델)** 로 바뀐 것이 출발점.

## 1. [확정] framerelay가 가져온 UI 단순화

| 항목 | EMU였다면 | framerelay |
|---|---|---|
| 몬 파일(.pk3) 선택 | 필요 | ❌ 불필요 (스위치끼리 직접 교환) |
| prod.keys | 필요 | ❌ 불필요 (암호화도 스위치끼리) |
| 사용자 입력 | 수십 가지 | 역할 + 세션 코드 + 자동감지 카드 |

### 브리지가 읽을 수 있는 정보
- ✅ 방 존재 + 방장 닉네임 (RFU 비콘 application_data — STEP 2 디코더 실측 완료: `host name='GIRL'`)
- ✅ 현재 인원, comm_id/scene_id(FRLG 판별), 채널·RSSI, 프레임 흐름량, 내 스위치 MAC(자동수집)
- ❌ 교환 카드 내용·트레이너 ID 상세 (AES 암호화 — 스위치끼리만 해독) → UI에 "우리는 교환 내용을 볼 수 없어요" 명시 가능

## 2. [확정] 사용자 여정 3막 (시작점으로 채택)

### 막 1 — 첫 실행 (1회)
환영 1장 → 자동 진단(가상화·디스크) → 설치 진행바(WSL·커널·usbipd 전부 자동) → 재부팅 후 자동 재개 → 동글 감지 → 완료

### 막 2 — 메인 (매 사용, 목표 30초)
```
🟢 준비 완료 · RTL8188EU 인식됨        ← 신호등 상태
   [방 만들기]      [참가하기]
   → 방 만들기: { 공방으로 열기 | 코드방으로 열기 }
   → 참가하기:  { 공방 리스트 보기 | 코드 입력 }
```

### 막 3 — 교환 중
연결 상태 계기판 (손 뗀 상태). 교환 자체는 스위치 게임 화면에서.

## 3. [확정] 공방(Public Room) 설계

| 항목 | 결정 |
|---|---|
| 방 2종 | 🏪 공방(리스트 노출) / 🔒 코드방(코드·QR로만) |
| **리스트 표시 정보** | **방 제목 · 방장 닉네임 · 현재 총 인원 · 신호강도 · 거주 지역(IP 기반)** |
| 닌텐도 정책 리스크 | 무시 — 공방 정식 제공 |
| 유저 매너 기능 | MVP 제외, **강퇴만 포함** (방장 전용 버튼) |

### 구현 메모
- **신호강도** = 방장 브리지 ↔ 릴레이 RTT 기반 (무선 RSSI는 상대에게 비가시라 리스트 불가). 표시: 막대 + ms
- **거주 지역** = 서버가 GeoIP(무료 DB)로 광역(시/도) 산출. **원본 IP 저장·표시 금지**
- 릴레이 서버는 필수 (NAT 통과 + 매치메이킹) — `relay/server.py`에 방 목록 API 추가 예정

## 4. [확정] 컴맹 원칙 5개

1. 전문용어 금지 — iface/MAC/session/monitor 금지어. "동글·방·코드"만
2. 버튼 2개 원칙 — 메인 화면 선택지 최대 2개
3. 에러는 문장 + 해결 버튼 1개 ("동글이 잠깐 멈췄어요 [복구]")
4. 고급 설정은 서랍에 (릴레이 주소, 로그)
5. 상태는 색으로 — 초록(준비)/노랑(대기)/빨강(문제+해결버튼)

## 5. [확정] UI 기술: 웹 프론트엔드 + 파이썬 백엔드 (PySide6 위젯에서 전환)

"이쁘게" 우선순위 상승에 따라 재검토 → **HTML/CSS/JS 프론트엔드 채택 방향**.

| 방식 | 디자인 자유도 | 번들 | 백엔드 | 판정 |
|---|---|---|---|---|
| **pywebview + WebView2** ⭐ | 최상 | 작음 (Win10/11 내장 웹뷰) | Python | 1차 채택 |
| PySide6 + QWebEngineView | 최상 | 큼 (Chromium 번들) | Python | 안전망 (동일 프론트 이식 가능) |
| PySide6 + QML | 상 | 중간 | Python | 새 언어 학습 필요 |
| Tauri | 최상 | 작음 | Rust | 백엔드 재작성 — 탈락 |
| Electron | 최상 | 큼 | Node | 과중 — 탈락 |

구조:
```
[SwitchTrade.exe]
├─ 화면 = HTML/CSS/JS (Figma 시안 → 직접 이식 가능)
├─ 그릇 = pywebview (Windows 내장 WebView2)
└─ 두뇌 = Python (WSL 제어·framerelay·릴레이) ↔ js_api 브리지
```
- 트레이드오프: 트레이·전역단축키 등 OS 연동은 별도 라이브러리 조합 필요 → PoC에서 검증, 문제 시 QWebEngine 경로로 슬라이드 (프론트 자산 보존)
- 검증 포인트: ①WebView2 런타임 미설치 PC 처리 ②트레이 상주(Q3) ③exe 패키징(PyInstaller+pywebview)
